## 3. Course Description

This course provides an in-depth exploration of data structures and algorithms using Python as the primary programming language. Participants will gain a comprehensive understanding of fundamental data structures such as arrays, linked lists, stacks, queues, trees, graphs, and hash tables, as well as various algorithms for searching, sorting, and manipulating these structures efficiently. 

The course covers both theoretical concepts and practical implementations from scratch, equipping students with the knowledge and skills necessary to analyze problems, design efficient algorithms, and implement them using Python. During the course, students will be introduced to real-world applications in business and finance that can be solved efficiently with data structures discussed in class.

## 5. Course Learning Outcomes (CLOs)

### 5.1. Complexity Analysis (G1)
- **CLO 1.1:** Explain the importance of time and space complexity.
- **CLO 1.2:** Describe the mathematical definition of Big-O notation.
- **CLO 1.3:** Apply Big-O notation to measure growth rates of functions.
- **CLO 1.4:** Analyze complexity of sequential and recursive functions using Big-O notation.

### 5.2. Data Structures & Basic Algorithms (G2)
- **CLO 2.1:** Understand Abstract Data Type (ADT) concepts.
- **CLO 2.2:** Explain common data structures and searching/sorting algorithms.
- **CLO 2.3:** Implement common data structures, searching, and sorting algorithms from scratch.

### 5.3. Problem Solving & Applications (G3)
- **CLO 3.1:** Identify suitable data structures and algorithms to solve specific problems.
- **CLO 3.2:** Implement algorithms or leverage Python libraries to solve real-world problems.

### 5.4. Autonomy & Responsibility (G4)
- **CLO 4.1:** Develop the ability to self-study and work independently.
- **CLO 4.2:** Develop the capacity to take personal responsibility and contribute effectively to team goals.

## 6. Teaching Plan (15-Week Syllabus)

| Week | Main Subject | Core Contents |
|---:|---|---|
| **1** | **Course Intro & ADT** | Syllabus introduction; Abstract Data Types (ADT); Built-in Python data structures & external libraries. |
| **2** | **Asymptotic Complexity & Big-O** | Running time & basic operation count; Asymptotic analysis; Big-O notation; Recursion, Divide & Conquer, Master Theorem. |
| **3** | **Searching & Simple Sorting** | Linear Search, Binary Search; Insertion Sort, Bubble Sort, Selection Sort algorithms and implementations. |
| **4** | **Advanced Sorting & Complexity** | Merge Sort, Quick Sort algorithms; Complexity analysis & comparative evaluation of sorting methods. |
| **5** | **Array & Linked Structures (P1)** | Array data structure & operations; Singly Linked List concepts, nodes, and operations. |
| **6** | **Linked Structures (P2)** | Doubly Linked List, Circular Linked List & practical implementation of list operations. |
| **7** | **Stack & Queue Data Structures** | Stack, Queue, Deque ADTs; Fundamental operations & application scenarios. |
| **8** | **Stack/Queue Applications & Review** | Real-world applications of Stack/Queue (Undo/Redo, Expression Parsing, Traversal) & Midterm review. |
| **9** | **Midterm Examination** | Computer-based / Written Midterm Test evaluating topics from Week 1 to Week 8. |
| **10** | **General Trees & Binary Trees** | Tree concepts & terminology; Binary Trees; Tree implementation & traversal algorithms (Pre-order, In-order, Post-order). |
| **11** | **Binary Search Trees (BST)** | Binary Search Tree structure; Searching, insertion, and deletion algorithms on BST. |
| **12** | **AVL Balanced Search Trees** | Tree balance concepts; AVL Trees; Single & Double Rotations & self-balancing mechanisms. |
| **13** | **Priority Queues & Heap Structure** | Priority Queue ADT; Heap data structures (Min-Heap, Max-Heap); Heap Sort algorithm. |
| **14** | **Hash Functions & Hash Tables** | Hash functions; Hash Table structure; Collision handling schemes (Chaining, Open Addressing). |
| **15** | **Course Summary & Final Review** | Systematizing complete course knowledge of DSAI1002, Q&A session & final exam preparation. |
