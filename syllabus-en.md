## 3. Course Description

This course provides an in-depth study of data structures and algorithms using the Python programming language. Students are equipped with a comprehensive understanding of fundamental data structures such as arrays, linked lists, stacks, queues, trees, graphs, and hash tables, along with efficient algorithms for searching, sorting, and data manipulation.

The course incorporates both core theoretical concepts and hands-on implementation of source code from scratch, enabling students to analyze problems, design optimal algorithms, and implement them in Python. Throughout the course, students explore practical applications in business and economics that can be effectively solved using the data structures and algorithms learned.

## 5. Course Learning Outcomes (CLOs)

### 5.1. Complexity Analysis (G1)
- **CLO 1.1:** Explain the role and significance of time and space complexity.
- **CLO 1.2:** Describe the mathematical definition of Big-O notation.
- **CLO 1.3:** Apply Big-O notation to measure function growth rates.
- **CLO 1.4:** Analyze the complexity of sequential and recursive functions using Big-O notation.

### 5.2. Data Structures & Fundamental Algorithms (G2)
- **CLO 2.1:** Understand the concept of Abstract Data Types (ADT).
- **CLO 2.2:** Explain common data structures and popular searching/sorting algorithms.
- **CLO 2.3:** Implement fundamental data structures, searching, and sorting algorithms from scratch.

### 5.3. Problem Solving & Applications (G3)
- **CLO 3.1:** Identify and select appropriate data structures & algorithms to solve real-world problems.
- **CLO 3.2:** Implement algorithms or utilize existing libraries to solve practical problems.

### 5.4. Autonomy & Responsibility (G4)
- **CLO 4.1:** Develop capacity for independent learning and self-study.
- **CLO 4.2:** Develop personal responsibility and contribution toward team objectives.

## 6. Course Syllabus (15 Weeks)

| Week | Main Topic | Core Content |
|---:|---|---|
| **1** | **Course Intro & ADT** | Course syllabus overview; Abstract Data Types (ADT); Built-in data structures in Python; Extension libraries. |
| **2** | **Asymptotic Complexity & Big-O** | Measuring runtime & basic operations; Asymptotic analysis; Big-O notation; Recursion, Divide & Conquer & Master Theorem. |
| **3** | **Searching & Simple Sorting** | Linear Search, Binary Search; Insertion Sort, Bubble Sort, Selection Sort. |
| **4** | **Advanced Sorting & Complexity Analysis** | Merge Sort, Quicksort; Evaluation and complexity comparison of sorting algorithms. |
| **5** | **Array & Linked Structures (P1)** | Array Data Structure; Array operations; Singly Linked List and fundamental operations. |
| **6** | **Linked Structures (P2)** | Doubly Linked List; Circular Linked List & practical lab operations. |
| **7** | **Stack & Queue Data Structures** | Stack, Queue, Double-ended Queue (Deque); Fundamental operations & application problems. |
| **8** | **Stack/Queue Applications & Review** | Real-world applications of Stack/Queue (Undo/Redo, Parsing, Traversal); Midterm review. |
| **9** | **Midterm Examination** | Computer-based / Written Midterm Test evaluating topics from Week 1 to Week 8. |
| **10** | **General Trees & Binary Trees** | Tree concepts & terminology; Binary Trees; Tree implementation & traversal algorithms (Pre-order, In-order, Post-order). |
| **11** | **Binary Search Trees (BST)** | Binary Search Tree structure; Searching, insertion, and deletion algorithms on BST. |
| **12** | **AVL Balanced Search Trees** | Tree balance concepts; AVL Trees; Single & Double Rotations & self-balancing mechanisms. |
| **13** | **Priority Queues & Heap Structure** | Priority Queue ADT; Heap data structures (Min-Heap, Max-Heap); Heap Sort algorithm. |
| **14** | **Hash Functions & Hash Tables** | Hash functions; Hash Table structure; Collision handling schemes (Chaining, Open Addressing). |
| **15** | **Course Summary & Final Review** | Systematizing complete course knowledge of DSAI1002, Q&A session & final exam preparation. |
